The QEC Model Zoo provides a common benchmark for comparing AI-based quantum error correction
decoders with established classical methods. It spans nine real-device datasets and eleven
full-decoder methods across multiple code families and hardware platforms.

The associated paper has been accepted to NeurIPS 2026 and is not yet publicly available.

[Explore the QEC Model Zoo](/qec-model-zoo) for an overview of the datasets, decoder families,
pre-decoding techniques, and model checkpoints. The codebase will be released when the
benchmark manuscript is published.
